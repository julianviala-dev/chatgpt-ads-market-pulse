# Product intelligence refresh

Refresh only from official OpenAI Ads/OpenAI Help Center sources allowlisted in config/product_sources.yaml.

For each capability relevant to current field signals capture:
- capability name
- official source URL
- current availability/scope
- what blocker it may mitigate
- what remains unresolved

This is a separate data plane. Never alter Market Temperature, prevalence or advertiser sentiment because a product capability exists.
